# 講師向け運用メモ

## 事前チェック

- ワークショップ前日までに `prepare_dataset.py` と `create_embeddings.py` を実行してください。
- `data/workshop/images/`、`metadata.csv`、`embeddings.npy` があることを確認してください。
- Colab で `notebooks/02_participant_workshop.ipynb` を開き、ボタン UI が表示されることを確認してください。
- 10枚程度ラベルを付け、「AIを更新する」で学習できることを確認してください。

## 3時間の進行例

### 固定確認セットを使う実験（更新版）

ローカル環境ではJupyterLabを使用します。3-Aで最大20枚の確認用画像に先に回答し、全モデルの学習から除外します。240枚なら残り220枚が学習用候補です。予測を見せずに確認用回答を決め、実験中は固定します。

最初に講師が「すべてのセルを実行」で画面を準備します。参加者は3-Aで確認用に回答し、4のボタンで学習用10枚→累計20枚→累計40枚と進めます。各段階で「この枚数で比較・記録」を押すと、通常AI・正則化設定違い・MLPをまとめて学習・記録します。「記録を見る」で結果を確認し、「次の段階へ」で追加回答します。セルの再実行は不要です。出題はランダム固定です。

各段階で両クラスの回答が必要です。一方だけなら目標枚数を超えて回答でき、実際の学習枚数で記録します。「増やせば必ず改善」「大きいモデルほど正解」とは説明しません。

回答・履歴は教材直下のJSONに自動保存します。再起動後も復元できますがAIは再学習します。同じPCで次の参加者が使う場合は「新しい参加者」から確認してリセットしてください。旧回答は日時付きJSONにバックアップします。提出にはCSV保存も使います。USB配布時は参加者の自動保存・バックアップJSONを混ぜないでください。

### 時間配分の目安

- 0:00-0:20 導入: AIは「正解」ではなく「人の好み」を学ぶことを説明
- 0:20-0:40 JupyterLabの画面を準備、確認用に回答
- 0:40-1:20 ラベル付け1回目、AI更新、TOP10を見る
- 1:20-1:35 ミニ座学: 特徴量、ラベル、分類器、少量データの不安定さ
- 1:35-1:45 休憩
- 1:45-2:20 累計20枚・40枚まで追加ラベル、比較・記録
- 2:20-2:40 実験: 慎重なAI、ふつうのAI、思い込み強めAIを比較
- 2:40-2:55 参加者ごとのAIの違いを共有
- 2:55-3:00 CSV保存、まとめ

## 座学で押さえるポイント

- ミニ講義用のスライド原稿は `docs/mini_lecture_slides.md` にあります。
- 今回のAIは「かわいい」の正解を知っているわけではありません。
- 画像は事前学習済みモデルで数字の特徴量に変換済みです。
- 当日は、その特徴量を使って軽い分類器だけを学習します。
- 「かわいい！」だけ、または「今回はちがう」だけでは境界線を引けません。
- ラベルが少ないと、たまたま選んだ画像に強く引っ張られます。
- 教えた例に合わせすぎると、まだ見ていない画像にも強く決めつけることがあります。これを過学習の入口として扱います。

## 過学習の見せ方

参加者ノートブックの「実験: AIの思い込みを見てみよう」では、同じラベルで3種類のAIを比べます。

- 慎重なAI: `C=0.1`
- ふつうのAI: `C=1.0`
- 思い込み強めAI: `C=1000`

中高生向けには、最初から「汎化性能」や「正則化」を詳しく説明しなくてかまいません。まずは「少ない例だけを信じすぎると、AIが強く決めつけることがある」と説明すると伝わりやすいです。

比較の問い:

- 推しTOP5は3つのAIで同じか、違うか
- 思い込み強めAIはスコアが0%や100%に近くなっていないか
- 自分がまだ教えていない画像にも、自信満々に点数を付けていないか
- ラベルを増やすと、結果は落ち着くか

## 詰まりやすいところ

- Colab でデータの場所が違う場合は、ノートブック先頭の `WORKSHOP_DIR` を変更します。
- 「AIを更新する」を押しても学習できない場合は、「かわいい！」と「今回はちがう」の両方を最低1枚ずつ付けているか確認します。
- `ipywidgets` が表示されない場合は、セルを上から順に再実行してください。
- 参加者の通信環境が不安定な場合に備えて、教材 zip は事前に Google Drive で共有しておくと安定します。

## 声かけの例

- 「このAIは全員共通の正解を探しているのではなく、あなたの好みをまねしようとしています」
- 「少ないラベルだとAIはまだ迷います。迷っている画像に教えてあげると、変化が見えやすくなります」
- 「今回はちがう、も大事な情報です。AIに境界線を教えるヒントになります」

### 40枚より先の追加学習

40枚の比較が終わったら、4の「自由に追加して学習する」を押せます。以後は残りの学習用写真に自由に回答し、「AIを更新する」で再学習します。「この枚数で比較・記録」も任意の枚数で使えます。10・20・40枚の比較記録と固定確認用の回答は保持します。自由追加の状態も自動保存・復元します。学習用写真にすべて回答すると回答ボタンは無効になります。
